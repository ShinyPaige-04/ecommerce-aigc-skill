# 统一留白产品视觉语言

本文件是 `ecommerce-aigc` 的唯一视觉语言。所有商品、品类、渠道和画幅都必须使用同一套留白产品版式；不得选择、混合或输出其他风格区域，也不得进行四维风格评分。

## 核心识别关系

`连续低干扰留白底色 + 商品背后唯一完整二维正圆色块 + 中至大比例完整商品 + 独立文字区 + 单一现代无衬线字体 + 柔和落地光影`

“生活型”只体现为自然、亲和、易理解的色温、材质与版面节奏，不通过人物、房间、户外环境或使用情节表达。

## 构图

- 先划分文字区、商品区和连续空白，再放置元素。文字不得覆盖、穿插或紧贴商品。
- 商品是唯一第一视觉入口，位于中轴、三分线焦点或左右分栏的主视觉区；不得缩成角落小图。
- 默认使用左文右物；若商品朝向相反，可镜像为右文左物。竖版可使用上文下物，但两区仍须完全分离。
- 使用稳定的水平、垂直关系和轻微不对称。禁止强对角线、旋转、悬浮、速度感、夸张透视和无必要越界裁切。
- 文字沿同一对齐轴形成一个主文字块；辅助信息靠近主文字块，不把多个文字组散落在商品四周。
- 信息通常为一个短标题、一个副标题和零至两个辅助信息组。价格、日期与 CTA 如为必需，应合并为一个下方信息组。

## 商品大小与空间比例

- 文字区约占画面宽度 `28–38%`，商品区约占 `45–60%`，两区之间保留画面短边 `4–7%` 的视觉间隔。
- 一般商品包围盒占画面面积 `40–60%`；竖向商品高度占画面高度 `58–80%`；横向商品宽度占画面宽度 `55–72%`。除非商品形态特殊，避免小于画面面积 `30%`。
- 外边距为画面短边的 `6–9%`；文字与商品轮廓的最小安全距离为短边的 `4–6%`；商品与画面边缘至少保留 `3–5%` 缓冲。
- 可见留白约占画面 `35–50%`，其中至少保留一块能完整容纳标题的连续空白。
- 商品必须完整、清晰、比例准确。包装名称、品牌标识、开口、把手、按键、轮子、材质接缝等身份特征不得被裁切、遮挡或重绘。
- 商品下方使用柔和接触阴影、小面积低台面或极浅承托面建立落地感，不用道具或场景填满空间。

## 字体与排版

- 整张海报优先只使用一个字体家族：现代黑体、人文无衬线或中性 Grotesk。中英文混排时选择字面大小和笔画粗细接近的组合。
- 主标题使用 `Semibold 600–700`；副标题、正文和标签使用 `Regular/Medium 400–550`。标题醒目但其视觉面积必须小于商品。
- 主标题、副标题、正文的建议字号比例为 `1 : 0.42 : 0.26`；重点数字可为主标题的 `0.50–0.70`。
- 标题通常一至三行；中文每行优先 `4–10` 字，英文每行优先 `2–5` 个词，按语义自然断行。
- 标题行距约为字号的 `0.90–1.10`；正文行距约为字号的 `1.30–1.55`。中文使用默认或轻微收紧字距，小号全大写英文标签可适度加宽。
- 默认左对齐，让标题、副标题与正文共享同一垂直起始线。即使商品居中，也要把文字组织成独立、稳定的小块。
- 标签与 CTA 可用小型圆角胶囊、细线框或半透明底板，但同一画面最多两种标签样式；主标题不得放进胶囊框。
- 文字色使用近黑、深灰或从商品主色提取的深色中性色，只允许一个小面积强调色。
- 禁止书法字、手写涂鸦、装饰衬线、超窄变形字、描边字、立体字、霓虹字、金属字和多重投影。

## 背景与颜色

背景不是未经设计的纯白，也不是另一个视觉主角。它的任务是用克制的色相关系、明确但柔和的明度分层和稳定的几何边界托起商品，同时留下连续、安静、可排字的留白。判断背景是否成功，不看它自身是否“漂亮”，而看商品轮廓是否更清楚、材质是否更真实、文案区是否更安静。

### 颜色分析顺序

生成背景前，先从商品原图读取六项信息，不能先套通用色板：

1. **主色相**：商品面积最大或品牌辨识度最高的颜色。
2. **辅色相**：占比次要但影响整体冷暖、品牌识别或结构分区的颜色。
3. **明度范围**：最亮表面、主体中间调和最暗结构分别位于什么层级。
4. **饱和度峰值**：商品中最鲜艳的区域在哪里；背景的任何颜色都不得与其争夺饱和度焦点。
5. **材质反射特征**：哑光、绒面、塑料、金属、玻璃、珠光或高反光表面分别需要怎样的边缘分离。
6. **轮廓清晰度**：检查商品四周哪些边缘最容易融入背景，尤其是白色、高光、透明、黑色和深色区域。

用一句内部判断完成分析：`[商品主色与明度] + [材质] + [最易丢失的边缘] + [需要偏统一或偏分离]`。之后再选择配色路径。

### 背景分层

- 背景固定由 `连续基础底色 + 一个辅助色系的标准二维正圆` 构成。除商品和真实接触阴影外，背景中不得再出现第二色块、过渡形、轨道或节点。
- **基础底色**覆盖约 `65–80%`，负责留白和整体色温。优先选择暖白、冷白、雾灰、奶油色、浅米色、燕麦色、淡灰粉、雾蓝灰、鼠尾草灰或极浅灰化品类色；避免未经处理的纯白和与商品完全同明度的底色。
- **正圆辅助色块**覆盖约 `12–28%`，负责分离轮廓、平衡画面或承托商品。其饱和度必须低于商品主色，局部对比不得强过商品内部最关键的结构对比。
- 若正圆使用低明度辅助色，其覆盖面积控制在 `8–18%`，并通过调整圆形直径和位置压住重心；不得铺满画面形成沉重暗底。
- 至少保留 `35–50%` 连续安静区域。这块区域不叠加纹理、光斑、渐变、装饰线或复杂色块，优先供标题和商品轮廓使用。
- 商品始终拥有画面最高的颜色辨识度、最清楚的关键轮廓和最强的局部明暗结构。背景可见但不主动“抢眼”。

### 唯一背景正圆

每张海报必须且只能使用一个主要承托形，该承托形必须是完整、标准的二维正圆形实色色块。正圆宽度与高度严格相等，宽高比固定为 `1:1`，轮廓完整闭合且全部位于画布内；不允许使用椭圆、半圆、拱形、圆角矩形、胶囊形、扇形、宽色带、边缘色块、无中心低对比渐变或任何其他替代形状。不同商品只能通过等比例调整正圆直径和移动圆心来适配，不得改变正圆形状。

背景几何固定为：`连续基础底色 → 一个完整二维正圆形色块 → 商品 → 真实接触阴影`。商品背后不得再出现第二色块、轨道、节点或辅助几何形。

#### 正圆的硬性几何规则

- 色块必须是数学意义上的标准正圆。宽度与高度严格相等，宽高比固定为 `1:1`，水平半径与垂直半径完全一致。
- 正圆必须整体位于画布内，几何轮廓完整闭合。不得被画布边缘裁切，不得只显示半圆、局部圆弧或缺口。
- 只允许对正圆进行**等比例缩放和平面位移**。适配不同商品时只能改变直径和圆心位置，禁止分别调整宽度与高度，禁止透视压缩、倾斜、拉伸或自由变形。
- 正圆使用均匀的二维实色填充。圆内颜色、透明度和明度保持一致，不使用渐变、光斑、纹理、描边、投影、内阴影、体积光或高光。
- 正圆不是球体、圆盘、洞口、窗户、行星、展台或空间装置。它不具有厚度、透视、反射、体积和发光效果。

#### 正圆的尺寸与位置

- 正圆只围绕商品区组织，圆心对准商品的主要视觉体积，再根据留白与轮廓分离需要轻微偏移。偏移量建议控制在商品展示区宽度或高度的 `3–8%`。
- 正圆直径通常占商品展示区宽度的 `75–95%`。若商品特别高、宽或形态特殊，仍保持 `1:1` 正圆，只调整直径与圆心，不改变形状。
- 商品位于正圆前方，可以遮住圆形中部。正圆在商品两侧、肩部或底部露出连续弧段；被商品遮挡不等于圆形被裁切，正圆几何本体仍必须完整存在。
- 商品顶部、底部或一侧可以超出圆形边界约自身包围盒的 `5–18%`，形成明确前后关系；但商品的品牌、开口、把手、按键、轮子、鞋底等关键结构不能恰好压在圆周切线上。
- 正圆必须与文字安全区完全分离，不穿过主标题、说明、价格、CTA 或关键信息组。若空间不足，缩小或移动正圆，不得裁切正圆或改造成椭圆。

#### 明确禁止的替代形状

- 禁止椭圆、半圆、拱形、圆角矩形、胶囊形、扇形、弧形色带、不规则曲线、自由形色块和渐变光斑。
- 禁止立体球体、玻璃球、发光圆盘、厚重径向渐变、光环、同心圆、细线轨道、扫描环、节点、刻度和任何科技仪表结构。
- 禁止通过裁切画布、遮罩、透视或局部隐藏，把非正圆形伪装成圆形。检查可见轮廓与推断出的完整几何，均必须符合标准正圆。
- 若模型生成了椭圆或任何变形圆，修正方式只能是恢复宽高相等、重新设置正圆直径和圆心位置；不得用其他形状补救。

#### 文字安全与场景边界

- 文字区应落在基础底色上，与正圆保持清楚间隔。主标题不能跨越圆周边界。
- 商品脚下只使用真实接触阴影或极浅无边界承托面。正圆不能被处理成桌面、房间、窗户、地平线或景观。

### 四种配色路径

根据商品选择一种路径，并让基础底色、承托色域、文字色和小强调色都服从这条路径。不要在同一张海报中同时使用同色、互补、邻近和深色强调等多套逻辑。

1. **同色系明度对比**：从商品主色提取色相，将基础底色显著提亮并降饱和，再用同色系深一阶正圆色块承托商品。适合商品色本身具有品牌辨识度、希望画面统一柔和，或材质需要安静呈现的情况。
   - 示例：酒红商品 → 暖白或淡灰粉底色 + 灰玫瑰正圆色块。
   - 示例：墨绿商品 → 燕麦色或极浅绿灰底色 + 鼠尾草灰正圆色块。
   - 控制：背景色与商品必须有明显明度差；若两者同明度，只换成同色系并不能形成轮廓。
2. **灰化互补色**：选择商品主色的互补色或近互补色，先大幅降低饱和度并调整明度，再以小面积正圆色块出现。适合商品边缘容易融入背景、需要更明确冷暖分离或颜色辨识度较高的情况。
   - 示例：红橙商品 → 暖白底色 + 灰青绿正圆色块。
   - 示例：蓝色商品 → 浅灰米底色 + 灰陶土或浅沙棕正圆色块。
   - 控制：互补色只能作为被灰化、减量的承托色，不能以鲜艳原色出现，也不能与商品形成节庆式或运动海报式撞色。
3. **低饱和邻近色**：使用色相环相邻颜色建立细腻层次，保持一致的冷暖方向和柔和过渡。适合食品、家居、服饰、个护和日常用品，以及需要亲和、轻松而非强烈分离的画面。
   - 示例：黄色商品 → 奶油底色 + 浅杏或灰橙正圆色块。
   - 示例：蓝绿色商品 → 雾蓝底色 + 浅灰绿正圆色块。
   - 控制：邻近色之间仍需保留一档以上的明度差，避免商品与背景融成一整块柔色。
4. **中性色底 + 低明度辅助色**：以暖白、浅灰、灰米或石色保持留白，再加入小面积炭灰、咖灰、深蓝灰、暗绿灰或灰棕。适合白色、浅灰、金属、透明材质或边缘不清晰的商品。
   - 控制：深色辅助色只负责勾勒局部轮廓或压住画面重心，面积与对比必须低于商品主体；不能变成整面深色背景或黑色展台。

### 配色路径选择优先级

按以下顺序判断，遇到满足条件的路径即可停止，不继续叠加其他逻辑：

1. 商品为白色、浅灰、透明、玻璃、银色或高反光材质：优先使用 `中性色底 + 低明度辅助色`。
2. 商品轮廓与背景容易融在一起，或主色高饱和：优先使用 `灰化互补色`。
3. 商品主色具有强品牌识别，且边缘本身清楚：优先使用 `同色系明度对比`。
4. 商品属于食品、家居、服饰、个护或日常用品，并希望亲和柔和：优先使用 `低饱和邻近色`。
5. 多色商品不直接套用多种路径：先选出面积最大或品牌最重要的主色，再从次要颜色中只保留一个最安静的辅助色，其余背景回到中性底。

### 商品与背景的匹配规则

- **深色商品**：使用明亮暖白、浅灰、灰米或浅同色系底色，再加一个“比底色深、比商品浅、比商品更灰”的承托色域。避免整面暗底和浓重暗角。
- **白色或浅灰商品**：不使用与商品同亮度的纯白底。选择蘑菇灰、灰米、雾蓝灰、鼠尾草灰或浅陶土，使商品最亮边缘与相邻背景产生明确明度差；优先通过底色和接触阴影分离，不加描边。
- **高饱和商品**：背景整体明显降饱和，商品保持画面唯一饱和度峰值。可用灰化同色系维持统一，也可用灰化互补色增强轮廓，但不得复制商品的鲜艳颜色铺满背景。
- **暖色商品**：需要分离时选冷灰、灰青绿或雾蓝灰；需要统一时选奶油、沙米、浅杏或淡陶土。暖色辅助域不能与商品同样鲜艳。
- **冷色商品**：需要分离时选暖灰、浅米、燕麦、灰杏或淡陶土；需要统一时选极浅蓝灰、灰青或浅绿灰。避免纯橙、纯黄或大面积蓝橙撞色。
- **金属商品**：使用石色、灰米、冷白或雾灰，并通过冷暖差显示轮廓。金色与玫瑰金只保留真实材质高光，不增加金色光晕、镜面舞台或黑金奢华背景。
- **玻璃、透明和高反光商品**：相邻背景需同时提供轻微色温差和明度差，配合真实接触阴影显示透明边缘。避免描边、白色外发光、强径向光斑和重复反射纹理。
- **绒面、皮革和哑光商品**：使用大面积柔和底色与一个完整正圆色块，不添加颗粒纹理模仿材质；通过轻微冷暖差和柔和侧光保留表面细节。
- **多色商品**：从次要颜色中选一个最安静、最低饱和的色相作为辅助色，其余背景保持中性。不得复制包装上的全部颜色、条纹或图案。

### 轮廓与对比校验

- 缩小到缩略图后，商品仍应是第一视觉入口；若辅助色块先被看到，降低其饱和度、面积或边界对比。
- 将画面暂时视为灰度图，商品关键轮廓仍应与相邻背景分开。若边缘消失，优先调整相邻背景明度，而不是加描边。
- 检查商品四周，不要求每一段边缘都高反差，但品牌标识、开口、把手、按键、轮子、鞋底、瓶盖等身份结构必须清楚。
- 文字区的底色应比商品承托区更安静。主标题不能跨越两种对比明显的背景，也不能落在渐变中心或色块边缘。
- 背景修正顺序固定为：`调整基础底色明度 → 调整冷暖 → 等比例调整正圆直径 → 移动正圆 → 轻微加强接触阴影`。禁止拉伸正圆，也禁止用外描边、外发光、硬光晕、第二辅助色或复杂纹理补救。

### 主体色与背景组合实例库

以下组合用于选色参考，不是必须逐字照搬的固定色板。每一行均给出两条可选路径：`组合 A` 偏统一柔和，使用同色系或邻近色；`组合 B` 偏轮廓突出，使用经过灰化的互补色或冷暖对比。单张海报只选一条路径。

色值用于明确颜色方向。实际生成时以商品原图为准，在相近色域内微调，不要求机械还原十六进制色值。

### 对比与用色边界

- 商品轮廓与相邻背景必须有清楚的明度差；若商品边缘开始融入背景，优先调整背景明度、色温或承托色域位置，不添加描边和外发光。
- 辅助色的饱和度通常低于商品主色，明暗对比也应低于商品内部的关键结构对比。
- 同一画面最多使用 `一个基础中性色 + 一个辅助色系 + 一个极小强调色`。中性色不计为竞争性色相；强调色面积控制在 `3–5%` 以内。
- 基础底色和正圆色块均使用均匀实色，不使用渐变；禁止渐变光斑、径向渐变、彩虹渐变、多段高饱和渐变、霓虹光晕和明显舞台灯光。
- 文字优先使用近黑、深灰或辅助色系中的最深色。不要为了呼应背景给不同文字使用多种颜色。
- 推荐视觉占比约为 `65–80%` 基础底色、`12–28%` 辅助色域、`3–5%` 文字与强调色；商品自身色彩独立计算，并保持第一视觉权重。
- 避免未经处理的死白背景、整面单色无层次背景、多个大面积鲜艳色块、高饱和互补撞色、复杂摄影纹理和可辨识场景。若品牌明确要求纯白底，则通过正圆色块、轻微冷暖差与接触阴影建立层次，不增加渐变。

## 商品图像与光影

- 使用清晰正面、三分之四侧面或符合品类认知的自然角度；保持原图的轮廓、比例、朝向、颜色、材质、品牌和结构。
- 使用柔和漫射光、轻微轮廓光与真实接触阴影，确保商品从背景中自然分离。
- 避免镜面强光、浓重暗角、戏剧性聚光、夸张透视、运动姿态和无依据的结构变化。
- 不加入人物、手部、房间、家具、植物、窗景、街景、自然风景、桌面道具或叙事情节。
- 如确有必要，只允许一个小型材质特写、色卡或局部细节窗，面积不超过画面 `8–15%`。

## 高信息量适配

所有信息量都必须装入同一版式，不得切换为促销拼贴或参数看板。

- 保留一个标题和一条共同对齐轴。
- 多个卖点合并为一组紧凑列表，不拆成多张卡片。
- 价格、日期、优惠和 CTA 合并为一个下方信息组。
- 信息拥挤时先缩小次级文字、减少装饰和压缩组间距，不先缩小商品。
- 禁止参数墙、徽章簇、爆炸贴纸和多个标题争夺注意力。
